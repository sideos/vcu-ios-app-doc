# User guide

How to use the wallet, in the order you will meet things.

| Page | What it covers |
|---|---|
| [Receiving a credential]({% link user-guide/receiving.md %}) | Scan or paste an offer, enter a transaction code, sign in at an issuer, read the consent screen, add the credential |
| [Your credentials]({% link user-guide/credentials.md %}) | The list, search, filters and sorting, the detail screen, names and tags, expiry, deleting |
| [Sharing a credential]({% link user-guide/sharing.md %}) | Who is asking, what would be shared, payments, declining and blocking, what happens afterwards |
| [Activity]({% link user-guide/activity.md %}) | The history of what was received, shared, refused and deleted, and the expiry notifications |
| [Settings]({% link user-guide/settings.md %}) | Privacy, security and lock, requesters, tags, developer mode, resetting the wallet |
| [Trust and security]({% link user-guide/trust-and-security.md %}) | What the wallet protects, how it decides whom to trust, and where its limits are |

{: .note }
> The wallet shows its **own name and logo** when a brand is imported (the screenshots in this guide use the sideos brand). Everything else is the same under any brand. See [Branding]({% link branding.md %}).
